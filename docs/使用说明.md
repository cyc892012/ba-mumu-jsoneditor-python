# 摸点小助手 Python 版 使用说明

欢迎使用**摸点小助手**！本工具专为使用 MuMu 模拟器游玩《蔚蓝档案》的玩家设计，帮助你在总力战、大决战等需要精准“摸点”的场景中，快速配置和管理键盘按键。

---

## 1. 简介

**摸点小助手**是一款专门用于编辑 MuMu 模拟器**键位方案**的工具。它的核心作用是：把“在游戏画面某个固定位置点一下”这个操作，精准绑定到你指定的键盘按键上，免去在模拟器里反复拖放、微调按键圆圈的麻烦。

在开始使用前，先用一句话了解几个基础概念：

- **键位方案**：MuMu 模拟器用来保存键盘映射的 JSON 文件（每个游戏、每套键位对应一个文件），本工具读写的就是这个文件。
- **相对坐标**：键位方案文件里保存的 0~1 之间的比例坐标，用来表示点击位置在屏幕宽高中的百分比，区别于按当前分辨率换算出的像素坐标。
- **宏指牌**：一种特殊的宏按键类型（在「ADB 触控采集」窗口中同一选项显示为「宏指令」），与普通「点击」按键共同构成工具支持的两类按键。
- **ADB**：安卓调试桥（Android Debug Bridge），本工具通过它直接读取你在 MuMu 模拟器屏幕上真实点击的坐标。

在所有取点方式中，**最推荐使用的是「ADB 触控采集」**。它会在你点击模拟器屏幕并抬起手指（鼠标）时直接记录真实落点，坐标与模拟器实际点击位置完全一致，精度最高，也不受窗口缩放或位置移动的影响。

## 2. 快速上手

如果你是第一次使用，只要跟着下面这 6 步，几分钟就能配好一套可用的摸点键位：

- **第 1 步：启动软件**
  双击「启动摸点小助手（成品）」快捷方式，或直接运行 `摸点小助手\摸点小助手.exe`。成品版自带运行环境，无需额外安装 Python。打开后窗口标题显示为「摸点小助手 3.0」。
- **第 2 步：选择键位方案**
  在主页面的「键位方案」卡片中，先在「区服」下拉框选择你的游戏区服（例如官服、B服、日服等），然后在下方的方案下拉框中选中你当前正在使用的键位方案。「自动同步」默认开启，开启时工具会自动跟随模拟器当前使用的方案。
- **第 3 步：确认分辨率**
  检查「分辨率」设置，先选类别（平板 / 手机 / 超宽屏 / 自定义），再选具体数值，确保与你的 MuMu 模拟器分辨率完全一致。（连接 ADB 后，模拟器的分辨率也会自动同步到主页面。）
- **第 4 步：打开「ADB 触控采集」并连接**
  先确认已在 MuMu 模拟器的「设备设置」→「开发者选项」中开启 ADB 调试，然后点击主页面底部的「ADB 触控采集」按钮。在新窗口中点击「自动获取」，再点击「连接并采集」，等待状态变为「采集中」。
- **第 5 步：采集点位并生成按键**
  回到模拟器画面，用鼠标依次点击你需要摸点的位置（比如学生头像、技能释放点等）。回到「ADB 触控采集」窗口，在坐标列表中点击每一行的「键帽」格并按下想绑定的键盘按键，勾选需要生成的行，最后点击「生成勾选」。
- **第 6 步：回到模拟器确认**
  切换回 MuMu 模拟器，在战斗或测试界面按下你刚才绑定的按键，确认实际点击位置是否准确生效。如果键位在模拟器里没有立即刷新，可确认方案是否已在模拟器中加载。

## 3. 主页面详解

主页面是所有操作的中枢，窗口从上到下依次分为**标题栏**、**「键位方案」卡片**、**「写入按键」卡片**、**底部工具区**和**状态栏**五个部分。

### 3.1 标题栏

窗口最上方为自定义标题栏，支持直接按住拖动以移动窗口位置。右侧提供三个常用窗口按钮：

- **置顶按钮**：让摸点小助手窗口始终保持在最前方，方便一边看模拟器画面一边操作。
- **最小化**：将窗口收起到任务栏。
- **关闭**：退出程序。

### 3.2 「键位方案」卡片

这一区域用于定位、切换和管理你的 MuMu 键位方案文件，以及设定当前使用的分辨率。

1. **「自动同步」开关**：位于卡片标题右侧，默认开启。开启后，工具会持续监控 MuMu 键位目录，自动跟随模拟器当前正在使用的键位方案；当方案文件被模拟器或外部程序修改时，工具会弹窗询问你是否重新加载。如果当前键位目录无效，工具会提示你先点击「获取路径」或「浏览」。
2. **「撤销」（Ctrl+Z）、「重做」（Ctrl+Y）、「历史」**：用于管理当前方案的修改记录。操作失误时可以直接撤销或重做；点击「历史」可以查看当前方案的操作历史列表，并直接跳转到某一步（跳转后会回写当前方案）。
3. **「区服」下拉框**：提供 官服 / B服 / 日服 / 国际服 / 其他 / 宇宙服 选项，用于按区服快速筛选对应的方案文件。
4. **方案下拉框**：列出当前区服下扫描到的所有键位方案文件。点击后支持直接输入文字进行搜索，也可以用键盘方向键选择、按回车确定。
5. **「浏览」按钮与拖放加载**：如果列表里没找到你的方案，可以点击「浏览」手动选择本地的 JSON 方案文件；你也可以直接把 JSON 文件拖进主窗口中加载。
6. **文件夹按钮**：点击后会在 Windows 资源管理器中打开当前方案所在的文件夹，并自动选中该方案文件，方便你备份或查找。
7. **「获取路径」按钮（放大镜图标）**：当 MuMu 安装路径变动或目录识别异常时，点击此按钮可重新定位 MuMu 键位目录。
8. **「分辨率」设置**：
   - 先选择类别（平板 / 手机 / 超宽屏 / 自定义），再选择具体的分辨率数值，**必须与模拟器的分辨率保持一致**，否则换算出的坐标会偏移。
   - 旁边的**锁形按钮**可以锁定当前分辨率，防止误改。
   - 点击「存为默认」可将当前分辨率保存为默认配置，点击「载入默认」则可一键恢复。
   - 当类别选择「自定义」时，可以保存多个自定义分辨率（名称旁会带有 `*` 标记），如需清理，可用旁边的删除按钮删掉当前选中的自定义分辨率。
   - 使用「ADB 触控采集」成功连接模拟器后，模拟器的分辨率会自动同步到主页面。

### 3.3 「写入按键」卡片

当你需要手动输入坐标、微调点位或复制已有按键坐标时，会用到这一区域。

#### 左侧坐标区

- **两组输入框**：「开发者 px」（X / Y）和「JSON 相对」（X / Y），中间以「⇄」分隔。
  - 「开发者 px」是按当前分辨率换算出的像素坐标。例如在 `1280×720` 分辨率下，屏幕左上角是 `(0, 0)`，右下角是 `(1279, 719)`。
  - 「JSON 相对」是键位文件内部保存的 0~1 比例坐标。
  - 修改任意一组中的数值，另一组都会按照当前分辨率自动完成换算。
- **「锁」复选框**：每组坐标上方都有一个「锁」复选框。勾选锁定后，该组输入框将不能手动编辑。
- **FX/FY 与「按锁定方向换算」**：坐标区下方会显示当前的 FX/FY（即当前分辨率宽高）。点击「按锁定方向换算」按钮，工具会以被锁定的那一组坐标为来源，重新换算另一组坐标（如果两组都被锁住了，工具会提示你至少解锁一组）。

#### 坐标精度说明

MuMu 模拟器只能把触控落点放在整数格上（相邻两格约相差 1 像素）。因此，当你手动输入带小数的坐标时，工具会自动为你选择最近的可达位置，并在「写入按键」标题右侧提示 `实际落点 x, y（偏差 ±…）`；如果正好落在整数格上（偏差为 0），则会显示 `实际落点与输入一致`。工具显示的坐标与模拟器实际点到的位置完全一致。

#### 右侧按键区

- **「按键」框**：用鼠标点一下输入框，再按下键盘上想绑定的按键即可完成捕获。
- **「检查」**：检查你输入的这个按键是否已经存在于当前方案中，并查看它当前的类型。
- **「读取坐标」**：从当前方案中读取该按键现有的坐标，并填入左侧坐标框中（此操作不会修改方案文件）。你可以用这个功能快速把一个键的位置复制给另一个键。
- **「类型」**：选择「点击」（普通点击）或「宏指牌」（宏按键）。
- **「强制替换已有键」**：勾选后，允许在写入时替换方案中已经存在的同名按键（实际覆盖前仍会弹窗向你确认）。
- **「修改并保存」**：将当前设置的按键与坐标正式写入方案文件；如果该位置或按键将覆盖已有点位，工具会弹窗确认，防止误操作。

#### 典型手动写入流程

- **第 1 步**：在「键位方案」卡片选好目标方案和正确的分辨率。
- **第 2 步**：在左侧「开发者 px」输入像素坐标（或在「JSON 相对」输入比例坐标）。
- **第 3 步**：点击右侧「按键」框，按下键盘上想绑定的键。
- **第 4 步**：在「类型」中选择「点击」或「宏指牌」（如要替换已有键，可勾选「强制替换已有键」）。
- **第 5 步**：点击「修改并保存」，完成写入。

### 3.4 底部工具区与状态栏

底部工具区分为两行功能按钮，点击即可打开对应的专用窗口：

- **取点**：
  - 「ADB 触控采集」（推荐）
  - 「鼠标回溯」
  - 「全屏快速摸点」
  - 「超宽屏转换」
- **工具**：
  - 「键位预设」
  - 「区域清空」
  - 「索引备份」
  - 「日志查看」

最底部的**状态栏**会实时显示最近一次操作的结果、当前分辨率、以及当前方案中包含的按键数量等信息。

## 4. ADB 触控采集详解

「ADB 触控采集」是本工具最核心、最推荐的取点方式。它通过 ADB 读取你在模拟器屏幕上真实点击的位置，并在手指（鼠标）**抬起**时记录坐标，确保采集到的坐标与模拟器实际触点完全一致。

### 4.1 准备工作

1. 在主页面中先加载好一个目标键位方案（否则生成按键时会提示未加载方案）。
2. 在 MuMu 模拟器的「设备设置」→「开发者选项」中开启 **ADB 调试**（打开窗口时，顶部也会提示：「连接前请开启 MuMu 的 ADB 调试。采集后绑定键帽并勾选，即可生成。」）。

### 4.2 连接区操作

1. **「ADB 路径」**：工具支持自动检测 `adb.exe`；如果未检测到，可点击「浏览」手动选择（MuMu 模拟器安装目录下自带 `adb.exe`）。
2. **「实例」与「端口」**：如果你开了多个 MuMu 模拟器，可以在「实例」下拉框中切换不同的多开实例，「端口」会随着所选实例自动联动（MuMu 12 单开默认端口为 `16384`，多开时各实例端口不同）。
3. **「自动获取」**：点击后自动检测当前正在运行的 MuMu 实例与对应端口，省去手动填写的麻烦。
4. **「清空设置」**：断开当前连接，清空已设置的 ADB 路径，并将端口恢复为默认的 `16384`。
5. **「连接并采集」**：点击后开始连接模拟器并进入采集状态。按钮旁边的两个状态标签会分别显示连接状态（「未连接 / 连接中 / 采集中」）和监听状态（「未监听 / 连续监听」），右侧则会显示读取到的模拟器分辨率（并同步到主页面）。连接后该按钮会变为「停止并断开」，点击即可结束采集并断开连接。

### 4.3 坐标列表管理

连接并进入「采集中」状态后，你在模拟器屏幕上每点击一次，坐标列表中就会增加或更新一行记录。

- **列表各列说明**：
  - 「选择」：勾选框，决定点击「生成勾选」时是否包含这一行。
  - 「序号」：当前行的序号。
  - 「屏幕坐标」：按模拟器分辨率换算的屏幕像素坐标。
  - 「相对坐标」：0~1 之间的比例坐标。
  - 「次数」：该位置被点击的累计次数（多次点击同一位置会自动合并到同一行并累加次数）。
  - 「键帽」：为这一行绑定的键盘按键。
  - 「类型」：该按键的类型，可选「点击」或「宏指令」。
  - 「删除」：删除该行的操作列。
- **绑定键帽**：用鼠标点击某一行「键帽」格，然后直接按下键盘上想要绑定的键；如果绑错了，按 `Esc` 键即可清除。注意，同一个按键不能同时绑定在两行上。
- **删除一行**：点击行尾的「×」按钮，或者选中该行后按键盘 `Delete` 键，也可以右键点击该行选择「删除此行」。删除后剩余行的序号会自动重新排列。如果删掉某个点位后再次在模拟器上点击同一位置，它会作为新的一行重新出现。
- **双击某行**：双击列表中的任意一行，可以直接把它的坐标填入主页面的坐标框中，方便查看或微调。

### 4.4 底部按钮

- **「应用到主窗口」**：把当前选中行的坐标填入主页面的坐标框（之后你可以在主页面手动检查并点击「修改并保存」）。
- **「清空列表」**：清空当前采集到的所有坐标记录。
- **「全选 / 取消」**：一键全选或取消全选列表中的所有行。
- **「生成勾选」**：把所有已勾选并且已绑定键帽的行，一次性写入主页面当前加载的方案中。如果有勾选的行尚未绑定键帽，工具会给出提示；如果将覆盖已有点位，则会弹窗确认。

### 4.5 快速生成模式（单次 / 连续）

如果你觉得在表格里逐行绑键还不够快，可以使用窗口下方的「生成」模式，无需操作表格，直接“点一下屏幕 → 按一下键盘”快速生成按键：

- **「生成」选项**：提供 `关闭` / `单次` / `连续` 三种模式。
  - **「单次」**：开启后，在模拟器里点击一下目标位置，再按下键盘上想绑定的按键，工具就会立刻用“最后一次采集到的坐标”生成该按键，随后自动关闭此模式。
  - **「连续」**：一直保持开启状态，每次执行“点击模拟器屏幕 → 按下键盘按键”都会自动生成一个按键，非常适合连续配置多个摸点位置。
- **「类型」**：选择 `点击` 或 `宏指令`，用来决定快速生成模式写入的按键类型。
- **防重复提示**：如果完全相同的按键已经存在于方案中，工具会提示已存在，而不会重复写入。

### 4.6 推荐完整流程

#### 方式一：批量勾选生成（适合一次性点完再统一配键）

- **第 1 步**：在主页面加载好目标键位方案。
- **第 2 步**：点击打开「ADB 触控采集」窗口。
- **第 3 步**：点击「自动获取」，确认实例与端口无误后点击「连接并采集」。
- **第 4 步**：切到模拟器，依次点击需要配置按键的各个位置。
- **第 5 步**：回到采集窗口的列表，为每一行绑定「键帽」、确认「类型」并勾选「选择」。
- **第 6 步**：点击「生成勾选」，完成后回到模拟器测试按键是否生效。

#### 方式二：单次 / 连续模式边点边生成

- **第 1 步**：完成连接并进入「采集中」状态后，在窗口下方将「生成」设为「单次」或「连续」，并选好「类型」。
- **第 2 步**：在模拟器上点击目标位置，紧接着按下键盘上想绑定的按键，即可直接写入方案。

## 5. 其他功能

除了主页面与「ADB 触控采集」外，底部工具区还提供了 7 个实用辅助功能，满足不同习惯与进阶场景：

### 5.1 「鼠标回溯」

打开后可实时查看当前鼠标在屏幕上的坐标位置，并支持使用窗口内设置的快捷键来保存或回溯坐标（默认快捷键为 `Ctrl+D` 保存、`Ctrl+F` 回溯，可在窗口内自行修改）。

### 5.2 「全屏快速摸点」

按 `F11` 让 MuMu 模拟器全屏显示（建议同时把小助手置顶），然后直接用鼠标在全屏的模拟器画面上取点并生成按键，工具会自动获取当前桌面分辨率。它同样提供单次和连续生成模式；如果你选择手动输入坐标，界面上也会像主页面一样显示实际落点提示。如果无法生成按键，请以管理员身份运行摸点小助手。

### 5.3 「超宽屏转换」

当你需要更换屏幕比例（例如从普通比例换到超宽屏）时，可以用此功能把一个分辨率下的单个按键或整份键位方案，自动换算到另一个比例的分辨率，工具会自动处理其中的黑边偏移问题。

### 5.4 「键位预设」

用于从预设方案中读取按键并写入当前加载的方案。窗口内提供「写入所有」「写入单个」「键位去重」「右下清空」「导入」「删除」「打开」等按钮，方便复用常用键位；覆盖方案中已有点位前会弹窗确认。

### 5.5 「区域清空」

用于批量删除指定矩形范围内的所有按键。你可以在右侧预览图上直接用鼠标拖出选框、拖动选框移动位置，或拖动边框与四角来调整大小，双击预览图即可恢复全屏范围；同时左侧坐标会实时同步。预览图中**红点**代表将被删除的按键，**紫点**代表将保留的按键，窗口底部还会实时显示待删除按键的数量。

### 5.6 「索引备份」

用于查看并恢复 MuMu 键位索引的自动备份记录。工具会自动对备份进行去重，最多保留 10 个历史备份，防止误删或索引损坏。

### 5.7 「日志查看」

用于查看软件运行日志以及操作失败的具体原因，同时提供快捷入口可直接打开日志文件所在的目录，方便排查问题或反馈 Bug。

## 6. 常见问题

- **Q1：连不上 ADB 怎么办？**
  请按以下顺序排查：
  1. 确认已在 MuMu 模拟器的「设备设置」→「开发者选项」中开启了 **ADB 调试**。
  2. 点击「ADB 触控采集」窗口中的「自动获取」，让工具重新识别路径与端口。
  3. 如果同时开了多个模拟器，确认「实例」和「端口」选择的是你要连接的那一个。
  4. 如仍无法连接，可点击「清空设置」重置连接配置后重试。

- **Q2：生成的按键位置不对、有偏移怎么办？**
  请检查主页面「键位方案」卡片中的「分辨率」是否与 MuMu 模拟器当前实际分辨率完全一致。建议直接连接「ADB 触控采集」，连接后工具会自动将模拟器的真实分辨率同步到主页面。

- **Q3：操作时提示“主窗口未加载 Json 文件”怎么办？**
  在进行「ADB 触控采集」生成按键等写入操作前，必须先在主页面的「键位方案」卡片中选中并加载一个键位方案（或通过「浏览」/ 拖入 JSON 文件加载）。

- **Q4：「自动同步」开关打不开怎么办？**
  请先点击「键位方案」卡片中的「获取路径」或「浏览」，确保设置了一个有效的 MuMu 键位目录后，再开启「自动同步」。

- **Q5：手动输入小数坐标后，提示有偏差是怎么回事？**
  这是因为 MuMu 模拟器本身只能将触点落在整数格上（相邻约 1 像素）。工具已经自动帮你选择了距离最近的可达位置，偏差不会超过约 0.5 像素，属于正常现象，且界面上提示的实际落点与模拟器最终点击的位置是一致的。

- **Q6：第一次启动比较慢？**
  安装或更新后第一次启动时，系统需要加载程序文件（杀毒软件也可能会先扫描一遍），因此会稍慢一些，之后再次启动就会快很多。
